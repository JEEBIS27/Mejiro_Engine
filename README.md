# メジロ式エンジン（メジロエンジン）

メジロ式は、複数のキーを同時に押すことで日本語を入力する速記システムです。
子音・母音・追加音の組み合わせで、片手で1音節、両手で2音節を一度に入力できます。
略語や動詞の活用、助詞の入力にも対応しています。

メジロエンジンは、メジロ式の変換処理をPlover・QMK・RMKで共通して利用するためのRust製エンジンです。

## メジロ式を導入する

使い方に合わせて、次のマニュアルへ進んでください。

| 使いたい環境 | 導入方法 |
| --- | --- |
| パソコン上のPloverで入力する | [Ploverへの導入](docs/installation-plover.md) |
| キーボードだけで入力する | [キーボードへの導入](docs/installation-keyboard.md) |
| 自作ファームウェアやアプリに組み込む | [エンジンの組み込み](docs/integration.md) |

Ploverではプラグインをインストールし、キーボードでは対応ファームウェアを書き込みます。
通常の利用にRustの開発環境は必要ありません。

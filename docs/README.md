# メジロエンジンのマニュアル

[プロジェクトのREADME](../README.md)

## メジロ式を使い始める

1. パソコンで変換する場合は[Ploverへの導入](installation-plover.md)、キーボード内で変換する場合は[キーボードへの導入](installation-keyboard.md)を読みます。
2. [仕様・使用例](examples.md)で基本入力と取り消しを試します。
3. 動作の意味を詳しく知りたいときは[エンジンの仕様](specification.md)を参照します。

## 自分のソフトウェアやキーボードに組み込む

1. [エンジンの組み込み](integration.md)でPlover・QMK・RMKの接続方法と配布するファイルを確認します。
2. [Rust API](rust-api.md)または[C API](c-api.md)で呼び出し方を確認します。
3. 略語・動詞を実行時に編集する場合は[辞書編集](runtime-rules.md)を確認します。
4. [仕様・使用例](examples.md)の入力列を使って、出力・文脈・取り消しを確認します。

## 用語

| 用語 | 意味 |
| --- | --- |
| ストローク | 同時に押したキーをまとめた1回分の入力 |
| 接続層（アダプター） | キー入力をエンジンへ渡し、結果をPloverやキーボードから出力する部分 |
| プレビュー | 状態を確定せず、入力に対する出力と次の状態を求めること |
| セッション | 確定入力の状態、履歴、マクロを保持する単位 |
| 削除単位 | 出力を取り消すために接続層が使う単位。UTF-8のバイト数とは別 |

文中のストロークは論理的なキー名です。キーボード上の物理位置は、使用するキーマップの配列表で確認してください。

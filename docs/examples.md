# 仕様・使用例

[マニュアル一覧](README.md) · [エンジンの仕様](specification.md) · [Rust API](rust-api.md)

ストローク欄は、同時押しした論理キーを表します。たとえば `KA-` は左手の `K` と `A` です。
各節は新しいセッションの初期状態から開始し、表の順に入力します。特記がなければ出力モードは `Kana` です。

## 基本入力

| ストローク | その入力による出力 |
| --- | --- |
| `KA-` | か |
| `KI-` | き |
| `K-T` | こと |
| `K-KAU` | ここ |
| `N-N` | なに |

物理キーの割り当ては、[Ploverへの導入](installation-plover.md)または[キーボードへの導入](installation-keyboard.md)から確認してください。

## 母音の引き継ぎ

| ストローク | 出力 | 説明 |
| --- | --- | --- |
| `KI-` | き | 母音Iを指定 |
| `S-` | し | 母音を省略し、直前のIを使う |
| `KA-` | か | 母音Aを指定 |
| `S-` | さ | 直前のAを使う |

登録語やコマンドは通常音節より優先されます。たとえば `K-` は登録語の「くる」なので、この母音省略の例には `S-` を使っています。

## 文脈で変わる助詞

次の例では、直前の出力の文法分類によって `k-k` が変わります。

| ストローク | 出力 | 説明 |
| --- | --- | --- |
| `n-*` | している | 後ろに名詞化の助詞を付けられる分類 |
| `k-k` | のが | 直前の分類を参照 |
| `k-k` | な | 今度は直前の助詞の分類を参照 |

次の各行は、初期状態から2ストロークを続けて入力する独立した例です。

| 入力列 | 出力列 |
| --- | --- |
| `K-T` → `ntk-` | こと → か |
| `K-KAU` → `ntk-` | ここ → へ |
| `N-N` → `ntk-` | なに → か |

語と助詞を同時に入力する場合は、そのストローク内の語を参照します。

| ストローク | 出力 |
| --- | --- |
| `Kntk-Tk` | ことへの |
| `Nntk-Nk` | なにかの |

## 取り消しと繰り返し

接続層が出力ごとに削除単位を登録した状態で試します。

| ストローク | 動作 | 出力先の内容 |
| --- | --- | --- |
| `n-*` | 「している」を入力 | している |
| `k-k` | 「のが」を入力 | しているのが |
| `#-` | 解決済みの「のが」を繰り返す | しているのがのが |
| `-U` | 直前の繰り返しを取り消す | しているのが |
| `-U` | 最初の「のが」を取り消す | している |
| `k-k` | 復元された文脈から「のが」を入力 | しているのが |

繰り返しは同じストロークを再変換する処理ではありません。
取り消しは文法・母音・保留した促音も復元します。外部編集などで履歴をリセットした後は、リセット前の入力を取り消しません。

## マクロの記録と再生

| ストローク | 動作 |
| --- | --- |
| `#n*` | n枠への記録を開始 |
| `n-*` | 「している」を出力し記録 |
| `k-k` | 「のが」を出力し記録 |
| `#-*` | 記録を停止 |
| `#n` | 保存した「しているのが」を再生 |
| `k-k` | マクロ再生後の文法は不明なので「な」を出力 |

再生時にはストロークや助詞を再判定しません。
再び `#n*` で記録を開始すると、その枠の前の内容を消して新しく記録します。
他の枠名と記録の扱いは[繰り返しとマクロ](specification.md#繰り返しとマクロ)を参照してください。

## STN単体と追加音

母音なしの `STN` はかなを作りません。追加音があれば、その音だけを出力します。各行は独立したストロークです。

| ストローク | Kana出力 | Romaji出力 |
| --- | --- | --- |
| `STN-` | 空 | 空 |
| `STNtk-` | っ | `ltsu` |
| `STNntk-` | ー | `-` |
| `KAntk-STNtk` | かーっ | `ka-ltsu` |

Romaji出力を使うキーボードでは、右列をIMEへ送ります。`STNtk` の「っ」は同じストロークで送られ、次の入力まで保留しません。

## ローマ字出力と促音

初期の切り替え先は `Romaji` です。

| ストローク | 出力・動作 |
| --- | --- |
| `#-n` | Romajiへ切り替える |
| `KAtk-` | `ka` を出力し、促音を保留 |
| `KA-` | `kka` を出力し、保留を解消 |

別の初期セッションで `#-n` → `KAtk-` → `-n` と入力すると、最後は `ltsu` を送ってからReturnを送ります。
ここでの文字列はエンジン出力です。画面に表示される内容は接続先とIMEの設定で決まります。

次の表はそれぞれ新しいセッションを作り、出力モードを選んで `n-*` → `k-nk` を入力した結果です。

| 出力モード | 2ストローク分の文字出力 |
| --- | --- |
| Kana | `しているのが、` |
| Romaji | `shiteirunoga,` |
| Jis | `dwe.kt@<` |

モードの選び方は[Rust API](rust-api.md#モードを選ぶ)または[C API](c-api.md#セッションapi)を参照してください。

## 文字とキー操作の組み合わせ

以下はそれぞれ独立した入力例です。

| ストローク | 文字列 | キー操作 |
| --- | --- | --- |
| `n-` | 空 | Space |
| `-n` | 空 | Return |
| `n-n` | 空 | Tab |
| `-TYI` | `（）` | 文字列の後にLeft |
| `-A` | 空 | Left |

`-TYI` のLeftはUTF-8バイト位置6に入ります。接続層は括弧を出力した後にカーソルを左へ移動します。
カーソル移動を含む出力はundo履歴を切ります。
